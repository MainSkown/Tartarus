# Debian 13 (trixie) base of python:3.12-slim. Run as root, before the uv sync layer.
#
#   apt-get install -y --no-install-recommends \
#       libpango-1.0-0 libpangoft2-1.0-0 fonts-liberation fonts-dejavu-core
#
# libpango-1.0-0 + libpangoft2-1.0-0 pull 15 more packages; apt reported +16.9 MB unpacked for the set with
#   fonts-liberation alone and +16.1 MB with fonts-dejavu-core alone (the combined set was built, not apt-measured).
# fonts-liberation (SIL OFL 1.1, 4.3 MB): Liberation Mono is metric-compatible with "Courier New", the design
#   system's --font-mono; Liberation Sans stands in for the sans stack.
# fonts-dejavu-core (Bitstream Vera licence, 2.3 MB): glyph fallback only. Without it the check, warning,
#   play and cross symbols render as empty boxes (tofu); with it Pango falls back per glyph.
#
# Python (added to backend/pyproject.toml dependencies; uv resolves the rest):

#                      pycparser, brotlicffi)
